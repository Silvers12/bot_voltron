# Visuels des compliments et insultes

Déposez ici une image PNG à fond transparent par commande :
- `compliment.png` pour `/compliment`
- `insulte.png` pour `/insulte`

Format conseillé : carré, 512 × 512, sujet centré. L'image est affichée en vignette à droite du texte.
Sans fichier, la carte est affichée sans vignette. Reconstruire le conteneur après un ajout.
