# Icônes des taux

Déposez ici une image PNG à fond transparent par taux, nommée d'après sa clé :
`chance.png`, `choupitude.png`, `suspicion.png`, `criminalite.png`, `loutritude.png`, `flemme.png`, `sagesse.png`, `chaos.png`.

Format conseillé : carré, 512 × 512, sujet centré. L'icône est affichée grisée et se remplit par le bas selon le taux.
Sans fichier, Voltron utilise une icône vectorielle de secours. Redémarrer le bot après un ajout.
